VidaSana - Prototipo (HTML + CSS + JavaScript)

Estructura:
  index.html      Pantallas (inicio, explorar, detalle, favoritos, hábitos, perfil, acceso)
  css/styles.css  Estilos (paleta en :root; el modo wireframe se activa con ?wire en la URL)
  js/app.js       Datos (CAT, RECS) y lógica (búsqueda, favoritos, hábitos, perfil, login)

Cómo abrirlo en Visual Studio / VS Code:
  Abrir la carpeta y ejecutar index.html (en VS Code: extensión Live Server > "Go Live").

Parámetros útiles en la URL:
  index.html#search        abre una pantalla directamente
  index.html?demo          carga un usuario de ejemplo
  index.html?wire          muestra la versión wireframe

Para entrar: cualquier correo válido y contraseña de 8 o más caracteres.
Los datos se guardan en localStorage del navegador.
